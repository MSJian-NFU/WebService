pip install graphviz

需要安裝獨立的 Graphviz 程式。  https://graphviz.org/download/
Windows：
從 Graphviz 官方網站下載頁面 下載 安裝檔。
執行安裝程式。在安裝過程中，請確保勾選「新增至系統 PATH」的選項。
安裝完成後，開啟命令提示字元或終端機，輸入 dot -V，如果顯示 Graphviz 的版本號，代表安裝成功。
